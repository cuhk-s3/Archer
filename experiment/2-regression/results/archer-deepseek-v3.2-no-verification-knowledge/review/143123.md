## Test Strategies

### Strategy 1: Mismatched FMF between fcmp and select

- **Target**: Test cases where fcmp has different FMF than select
- **Rationale**: The fix assumes FMF from select should be used, but there may be cases where fcmp has stricter flags that should be preserved
- **Expected Issue**: Incorrect min/max pattern recognition due to ignoring stricter fcmp flags

### Strategy 2: NoNaNs flag propagation from fcmp

- **Target**: Test cases where fcmp has noNaNs but select doesn't
- **Rationale**: The fix only propagates noNaNs from fcmp if CmpI->hasNoNaNs(), but other FMF flags from fcmp are ignored
- **Expected Issue**: Missing noNaNs flag could cause incorrect NaN handling in pattern matching

### Strategy 3: Vector types with mixed FMF

- **Target**: Vector select/compare patterns with FMF
- **Rationale**: Vector operations may have different FMF handling or edge cases
- **Expected Issue**: Incorrect pattern recognition for vector min/max operations

### Strategy 4: Cast operations with FMF

- **Target**: Test cases with type casts in select patterns
- **Rationale**: The fix modifies lookThroughCast which sets FMF flags for FPToSI/FPToUI casts
- **Expected Issue**: Incorrect signed zero handling for cast operations

### Strategy 5: Recursive pattern matching depth

- **Target**: Deeply nested select patterns with FMF
- **Rationale**: The FMF parameter is passed through recursive calls but may not be properly preserved
- **Expected Issue**: FMF flags lost during recursive pattern matching
