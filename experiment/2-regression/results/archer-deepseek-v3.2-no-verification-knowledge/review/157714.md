## Test Strategies

### Strategy 1: Mixed GEP chain flags intersection

- **Target**: GEP chains with mixed flags (nuw/nusw/inbounds)
- **Rationale**: The fix uses CommonPointerBase::compute which intersects flags across GEP chains. If flags are incorrectly intersected (e.g., nuw & nusw = none when only one has nuw), the transformation may incorrectly apply or fail to apply, leading to missed optimizations or incorrect poison propagation.
- **Expected Issue**: Incorrect flag intersection causing missed optimization or incorrect poison generation when comparing GEP chains with mixed flags.

### Strategy 2: Vector GEP chain handling

- **Target**: Vector GEP chains with scalable/fixed vectors
- **Rationale**: The fix may not properly handle vector GEP chains where indices or pointers are vectors. EmitGEPOffsets may not correctly handle vector scaling or type conversions, leading to incorrect offset calculations.
- **Expected Issue**: Incorrect offset calculation for vector GEP chains, leading to wrong comparison results.

### Strategy 3: GEP chain with addrspacecast

- **Target**: GEP chains crossing addrspacecast boundaries
- **Rationale**: CommonPointerBase::compute may not properly handle addrspacecast between different address spaces. The fix assumes same pointer types, but addrspacecast changes pointer type while preserving value.
- **Expected Issue**: Incorrect base pointer identification or offset calculation when GEP chains cross addrspacecast boundaries.

### Strategy 4: Multiple uses of intermediate GEPs

- **Target**: GEP chains where intermediate GEPs have multiple uses
- **Rationale**: The fix uses RewriteGEPs=true which may incorrectly rewrite GEPs that have multiple uses, potentially breaking other uses of those GEPs.
- **Expected Issue**: Incorrect rewriting of GEPs with multiple uses, breaking SSA semantics or other optimizations.

### Strategy 5: Signed vs unsigned comparison with mixed flags

- **Target**: Signed comparisons with GEP chains having partial nowrap flags
- **Rationale**: The fix checks CanFold(Base.LHSNW) but may not properly handle signed comparisons when only some GEPs in the chain have nusw flags. The transformation may incorrectly convert signed to unsigned comparisons.
- **Expected Issue**: Incorrect comparison predicate transformation for signed comparisons with partial nowrap flags.
