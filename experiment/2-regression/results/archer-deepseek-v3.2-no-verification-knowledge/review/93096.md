## Test Strategies

### Strategy 1: Vector Type Mismatch

- **Target**: Vector trunc instructions with nsw/nuw flags
- **Rationale**: The patch uses getScalarSizeInBits() for vector types but may incorrectly handle vector splat constants or vector element ranges. The fix assumes scalar analysis works for vectors, but vector materialization issues could cause type mismatches.
- **Expected Issue**: Type mismatch when replacing vector trunc with scalar constant or incorrect flag inference for vector elements

### Strategy 2: Wrapped ConstantRange Edge Cases

- **Target**: Trunc instructions with wrapped ConstantRange inputs
- **Rationale**: getActiveBits() and getMinSignedBits() may give incorrect results for wrapped ranges. For example, a ConstantRange that wraps around zero may have getActiveBits() <= DestWidth but still overflow when truncated.
- **Expected Issue**: Incorrectly inferring nsw/nuw flags for wrapped ranges leading to miscompilation

### Strategy 3: Empty ConstantRange Handling

- **Target**: Trunc instructions with empty ConstantRange inputs
- **Rationale**: Empty ConstantRange returns 0 for getActiveBits() and getMinSignedBits(), which would incorrectly satisfy <= DestWidth condition, leading to false nsw/nuw inference.
- **Expected Issue**: Inferring nsw/nuw flags for impossible values (empty range)

### Strategy 4: Mixed Signed/Unsigned Analysis

- **Target**: Trunc instructions where signed and unsigned analysis conflict
- **Rationale**: The patch checks nsw and nuw independently, but there may be cases where one is valid and the other isn't, or where the analysis order matters. The early return when both flags are present may miss refinement opportunities.
- **Expected Issue**: Missing optimization when only one flag can be inferred or incorrect flag inference due to analysis order

### Strategy 5: Vector Element-Specific Ranges

- **Target**: Vector trunc with non-uniform element ranges
- **Rationale**: The patch uses scalar analysis for vectors, but if vector elements have different ranges (e.g., from select or shuffle), the scalar range may be conservative while individual elements could have nsw/nuw.
- **Expected Issue**: Missing nsw/nuw flags for vector elements that individually satisfy conditions
